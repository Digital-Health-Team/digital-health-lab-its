Actor Key Use Cases Auth Required
👤 Guest Browse, view all public content, register, login No
🎓 Mahasiswa Book services, submit projects, register for trainings, upload payment proofs, chat with admin Yes + Email Verified
🙍 User Publik Book services, upload payment proofs, chat with admin Yes + Email Verified
🔬 Lab Admin Review briefs, set metrics/price, add progress, verify payments, manage all content Yes + Role: admin_lab
📦 Warehouse Admin Verify/flag materials, manage raw materials, restock, scan QR codes Yes + Role: admin_gudang
⚙️ Super Admin All of the above + user/role management, CMS control Yes + Role: super_admin

Three-way unique stock item_stocks has a unique constraint on (raw_material_id, color_id, lab_id) — one row per material+color+lab combination
Polymorphic: attachments attachable_type + attachable_id → Service, Tool, OpenSourceProject, ServiceProgressUpdate, Reimbursement, Product
Polymorphic: issue_reports reportable_type → Tool, RawMaterial, Inventory (or null for free-form reports)
Polymorphic: notifications notifiable_type → User (standard Laravel Notifiable)
Dual role assignment users.role_id is the primary role; user_roles pivot allows multi-role assignment with session-based switching
Payment gating 30% DP termin is auto-created when price is set; booking_payments.verified_by + status paid unlocks printing stage
